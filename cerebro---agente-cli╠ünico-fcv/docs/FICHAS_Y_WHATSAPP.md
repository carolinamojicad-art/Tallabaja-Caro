# Ficha individual y WhatsApp de Talla Baja

La fila y el botón de ID abren la ficha del registro seleccionado. Contiene perfil clínico, antropometría, seguimiento y datos del programa. No crea consultas, fechas, grupo sanguíneo, antecedentes ni nombres ausentes del Excel. Las gestiones son las del motor CE y no modifican la fuente.

Desde Preparar WhatsApp o Mensajes se abre un compositor con selección de paciente, número editable y texto para revisión. El número de pruebas indicado por la usuaria es +573242432326. Abrir WhatsApp genera un enlace wa.me; el usuario revisa y envía el mensaje dentro de WhatsApp. No hay integración con Business API, envío automático, acuses de entrega ni lectura.

La bitácora se guarda en localStorage del navegador, no en GitHub ni en un servidor. Apertura solicitada no significa enviado. Envío confirmado por usuario solo se registra por acción explícita del usuario. No se enviaron mensajes durante las pruebas.
